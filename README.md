# memtray

[![CI](https://github.com/ftnick/memtray/actions/workflows/ci.yml/badge.svg)](https://github.com/ftnick/memtray/actions/workflows/ci.yml)

Lightweight RAM usage tray app written in Rust.

Build

```bash
cargo build --release
```

Run

```bash
# run the tray app
cargo run --release

# open history window
cargo run --release -- --history
```
